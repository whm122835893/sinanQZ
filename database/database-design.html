一、设计决策汇总

#决策属性
1sold_out 与 status 合并为 status 枚举（upcoming/onsale/soldout）规范确认
2is_lucky 替换为 source 枚举（purchase/blindbox/transfer/airdrop/synthesis/lucky_draw）规范确认
3user_collectibles 不加 quantity，每份藏品一行（数字藏品非同质化）规范确认
4挂单快照字段全部移除，通过 collectible_id JOIN 取实时数据规范确认
5公告与新闻合并为 announcements 表，type 字段区分规范确认
6建立 system_configs 存储运营参数，禁止硬编码（限购/超时/冷却/签到奖励）规范确认
7is_consigned 保留为反规范化标记，便于快速查询寄售状态规范确认
8acquired_price 非购买来源（抽奖/合成/转赠/空投）存 0规范确认
9不加 order_items 子表，每笔挂单生成独立订单规范确认
10lucky_draw_prizes 独立建表管理奖品池规范确认
11transfers 必须包含 to_user_id，支持双向查询规范确认
12artifacts.tags 使用 JSON 数组存储规范确认
13空投藏品 source='airdrop'，通过 airdrop_record_id 溯源规范确认
14钱包独立建模：payments.payment_method='balance' 依赖 wallets 表；司南币以 points 字段单独记账（补回 Wallet.vue 钱包资产与流水）查缺补漏
15寄售手续费与 3 分钟冷却落库：fee_rate / fee_amount / actual_amount / cooldown_until（补回 consign.fee/actual + CONSIGN_COOLDOWN）查缺补漏
16盲盒开启即消耗：开盒将原 user_collectibles 置 consumed，同时生成新资产 source='blindbox'（替代 opened 布尔标记）查缺补漏
17抽奖奖品类型化：prize_type(collectible/points/none) + coin_amount；lucky_draw_records.user_collectible_id 可空（谢谢参与无资产）查缺补漏
18邀请关系独立 invite_records 表：注册链接 ?code= 绑定邀请人，一人仅能被邀请一次（空投业务逻辑已引用该表但清单缺失，补回）查缺补漏
19纯日志/明细表（wallet_transactions、synthesis_record_items、lucky_draw_records、user_favorites、airdrop_snapshots）省略 updated_at查缺补漏

四、实体关系说明

users ─1:1─ wallets                     users ─1:N─ wallet_transactions（纯流水）
users ─1:N─ user_collectibles ─N:1─ collectibles ─N:1─ categories
user_collectibles ─1:1─ resale_listings（在售期间唯一）        挂单不复制快照（决策4）
user_collectibles ─1:1─ transfers（转赠中冻结 frozen）
users ─1:N─ orders ─1:1─ payments       orders.resale_listing_id → resale_listings（市场单）
resale_listings ─N:1─ collectibles      地板价 = MIN(price) WHERE status='selling'
collectibles ─1:1─ blind_boxes ─1:N─ blind_box_items ─N:1─ collectibles（奖品，自关联 M:N）
synthesis_activities ─1:N─ synthesis_materials ─N:1─ collectibles（材料 M:N）
synthesis_activities ─N:1─ collectibles（result 产物）
synthesis_records ─1:N─ synthesis_record_items ─N:1─ user_collectibles（消耗明细）
lucky_draw_prizes ─1:N─ lucky_draw_records ─N:1─ users
check_in_records ─N:1─ users（uk_user_date 每天一次）
airdrop_activities ─1:N─ airdrop_records / airdrop_eligibilities / airdrop_snapshots
airdrop_records ─1:N─ user_collectibles（source='airdrop' 溯源，决策13）
invite_activities ─1:N─ invite_records（inviter_id / invitee_id 双向）
invite_records ─1:1─ airdrop_records（邀请双方奖励经空投落账）
artifacts（文物）、announcements（公告/新闻）、banners、community_groups 为独立内容域
system_configs / site_settings 为全局 KV 配置，无外键
